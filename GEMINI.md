# Project & Development Guidelines

## Testing & Local Environment
- **Go Tests**: You can run tests locally using Go. If Go is not installed on this machine, install it (e.g., using `winget install GoLang.Go`).
- **Server Endpoint & Credentials**: The Decypharr server runs on `http://192.168.31.84:8282`, where credentials for PikPak (and other services) can be obtained if needed.
